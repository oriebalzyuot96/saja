# Saja Al-Shannaq · Portfolio

Portfolio and CV of **Saja Al-Shannaq (سجى الشناق)**, Software Team Leader and Senior Software Engineer (.NET, Angular, React).

**Live:** https://oriebalzyuot96.github.io/saja/ · العربية: https://oriebalzyuot96.github.io/saja/ar/
**CV (PDF):** https://oriebalzyuot96.github.io/saja/Saja-Al-Shannaq-CV.pdf

- Astro 5 static site with English and Arabic (RTL) pages and a "sky & sage" theme in light and dark.
- All content lives in `src/data/profile.ts`. The CV source is `tools/cv/cv.html`.
- Accessibility drawer (`Ctrl+,`), command palette (`Ctrl+K`), synthesised UI sounds, and reduced-motion support.

```bash
npm install
npm run dev
```
Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml`.
